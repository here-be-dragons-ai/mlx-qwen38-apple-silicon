## `#2356` vs `0035`

`#2356` (fblissjr, opened 09-24, cites our 0.7.0 reproduction) fixes the same
case one level up: `APCCoordinator.merge_rows` returns a lone restored row's own
warm cache instead of merging it into batch caches, so Qwen3.5's single-row
shortcut is never entered. That is also why *cold* decode was never affected —
a cold single-row prompt already gets plain caches in `PromptProcessingBatch`.

Measured equal here. **`0035` stays**, because it covers a case `#2356` does
not: a batch that *shrinks* to one row (a `MAX_NUM_SEQS>1` profile without a
drafter). If `#2356` is what upstream merges, re-measure without `0035`; if the
ratio holds, drop it — our shipped profiles are single-slot.

Upstream comment drafts for both PRs: [pr-2336-2356-comment-draft.md](pr-2336-2356-comment-draft.md).
